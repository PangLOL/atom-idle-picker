# Atom idle frame picker

A 15 fps preview for choosing Sonic's 8 idle frames on the Atom S3R dashboard.

Check the frames you want; the preview loops only that pick. Five checked frames means a 5-frame loop, with no extra hold steps.

Sprites are faithful recreation by fans with reference to the E3 Sonic Rush DS E3 placeholder sprites, © SEGA -- fair use and commission is not an issue.

This site is separate from the [Atom OTA Pages](https://panglol.github.io/atom-s3r-ota/).
